# Vidhi Doshi — Urban Designer Portfolio

A lightweight, responsive HTML/CSS/JavaScript portfolio adapted from the referenced Figma-style portfolio approach and restructured for an urban designer / architect.

## What to edit

1. Replace the project deck placeholders in `script.js`:
   `PASTE_GOOGLE_DRIVE_LINK_HERE`
2. Replace the SVG placeholders inside `assets/images/` with real project hero images.
3. Add Vidhi's resume as `assets/Vidhi-Doshi-Resume.pdf`.

## Run locally

Open `index.html` in a browser, or use VS Code + Live Server.

## Publish

This is static HTML/CSS/JS and can be deployed directly to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any standard web host.

## Content strategy

The site intentionally keeps project descriptions short. The full PDF/PPT presentation stays in Google Drive and is opened through each project card, keeping the website visual and easy to scan.


## Theme
- Light/dark mode toggle in the header.
- First visit follows the browser/system color preference.
- Manual choice is remembered in localStorage as `vidhi-theme`.


Theme: Light is the default on first visit; the sun/half-moon icon toggles Light ↔ Dark and the choice is remembered. A custom SVG favicon is included at assets/favicon.svg.


### Favicon
The browser tab uses the generated Vidhi V monogram in light/dark variants and swaps with the site theme.
